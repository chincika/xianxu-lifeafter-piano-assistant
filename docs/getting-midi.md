# 获取和导入 MIDI

弦序的“获取乐谱”页面提供开放曲库、外部网站和第三方工具的入口。所有外部页面都通过系统默认浏览器打开；弦序不会自动安装或执行用户脚本，也不会读取浏览器账号、密码、Cookie 或访问记录。

## 优先使用开放曲库

[Mutopia Project](https://www.mutopiaproject.org/) 收录公版及 Creative Commons 乐谱，许多作品同时提供 MIDI。下载前请查看作品页面标注的具体许可证；需要署名或以相同方式共享时，应保留对应信息。

## 在自己的浏览器中使用第三方工具

1. 自行选择用户脚本管理器：
   - [Violentmonkey](https://violentmonkey.github.io/)
   - [Tampermonkey](https://www.tampermonkey.net/)
2. 阅读第三方项目的说明和源码，再决定是否安装：
   - [midishow-downloader-js](https://github.com/Saobby/midishow-downloader-js)
3. 打开 [MidiShow](https://www.midishow.com/) 搜索作品。
4. 确认页面显示的许可、积分和原作品权利要求。
5. 下载完成后回到弦序，点击“导入 MIDI”选择 `.mid` 或 `.midi` 文件。

## 来源和使用说明

- 外部网站和脚本由第三方独立维护，与弦序没有隶属或担保关系。
- 是否安装脚本、允许哪些浏览器权限以及下载哪些文件，由用户自行决定。
- 请仅获取和使用自己拥有相应权利或授权的作品，并遵守来源网站的使用规则。
- 不要使用这些入口批量抓取、转售或再次传播他人的作品。
- 第三方项目失效、改变行为或出现安全问题时，弦序无法保证其可用性。
